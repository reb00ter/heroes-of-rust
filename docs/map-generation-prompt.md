# Промпт для генерации карт — Heroes of Rust

Сгенерируй карту для игры Heroes of Rust в формате RON. Верни только валидный RON-файл без пояснений и markdown-обёрток.

---

## Полная схема формата

```
(
    width:  <u32>,      // ширина карты в тайлах (рекомендуется 10–40)
    height: <u32>,      // высота карты в тайлах (рекомендуется 10–30)

    // Перечисляются ТОЛЬКО нестандартные тайлы.
    // Все остальные позиции — Ground по умолчанию.
    obstacles: [        // непроходимые скалы/стены
        (x, y),         // x в [0, width-1], y в [0, height-1]
        ...
    ],
    water: [            // непроходимая вода
        (x, y),
        ...
    ],

    resource_piles: [   // кучки золота на карте
        (pos: (x, y), gold: <u32>),
        ...
    ],

    towns: [
        (
            id:           <u32>,       // уникальный ID города (0, 1, 2, ...)
            pos:          (x, y),
            daily_income: <u32>,       // золото игроку в начале каждого дня
            recruits: [
                (id: "<unit_id>", count: <u32>),   // начальное кол-во для найма
                ...
            ],
        ),
        ...
    ],

    neutral_armies: [
        (
            pos:   (x, y),
            units: [
                (id: "<unit_id>", count: <u32>),
                ...
            ],
        ),
        ...
    ],

    hero: (
        pos:             (x, y),     // стартовая позиция героя
        name:            "<String>", // имя героя (ASCII)
        movement_points: <u32>,      // очки движения в ход (рекомендуется 8–12)
        army:            [
            (id: "<unit_id>", count: <u32>),
        ],
        starting_gold:   <u32>,      // начальное золото игрока
    ),
)
```

---

## Доступные типы существ (`unit_id`)

Существа определены в `assets/data/units.ron`. Для ссылки из карты используй только ASCII `id`:

| id          | Название    | damage | hp | cost | daily_growth |
|-------------|-------------|--------|----|------|--------------|
| `peasant`   | Крестьянин  | 1      | 5  | 25   | 5            |
| `swordsman` | Мечник      | 3      | 10 | 75   | 2            |
| `goblin`    | Гоблин      | 2      | 5  | 0    | 0            |
| `orc`       | Орк         | 4      | 10 | 0    | 0            |
| `troll`     | Тролль      | 8      | 25 | 0    | 0            |

`daily_growth: 0` — нейтральные существа, не пополняются в замке.

---

## Ограничения (валидационные правила)

1. Все позиции `(x, y)` должны быть в пределах `[0, width-1] × [0, height-1]`.
2. Объекты (`resource_piles`, `towns`, `neutral_armies`, `hero`) не должны стоять на `obstacles` и `water`.
3. Нейтральный отряд и город не могут занимать одну клетку.
4. Герой не может стоять на клетке с нейтральным отрядом, городом или ресурсом.
5. Каждый `town.id` должен быть уникальным.
6. В одной армии (нейтрал или герой) — не более 7 стеков (`MAX_ARMY_SLOTS = 7`).
7. Все `id` существ в карте должны присутствовать в `assets/data/units.ron`.
8. `obstacles` и `water` не должны перекрываться.

---

## Рекомендации по балансу нейтральных отрядов

| Сложность | Примеры                                    | Суммарная сила |
|-----------|--------------------------------------------|----------------|
| Лёгкий    | 3–6 гоблинов (`goblin`)                    | damage×count ≈ 6–12 |
| Средний   | 3–5 орков (`orc`)                          | damage×count ≈ 12–20 |
| Тяжёлый   | 2–3 тролля (`troll`)                       | damage×count ≈ 16–24 |

Рекомендуется иметь 2–5 нейтральных отрядов разной сложности.  
Стартовая армия героя (5 крестьян) легко проходит гоблинов, с трудом — орков, не может без потерь победить троллей.

## Полный пример — `assets/maps/default.ron`

```ron
(
    width:  20,
    height: 15,

    obstacles: [
        (3,0),(4,0),(3,1),
        (9,3),(9,4),(9,5),
        (14,1),(14,2),(15,8),(15,9),
        (6,12),(7,12),(7,13),
        (11,11),(12,11),
    ],
    water: [
        (0,13),(0,14),(1,14),(2,14),
        (19,0),(19,1),(18,0),
        (18,14),(19,14),(19,13),
    ],

    resource_piles: [
        (pos: (2,5),   gold: 150),
        (pos: (7,1),   gold: 200),
        (pos: (10,9),  gold: 250),
        (pos: (15,3),  gold: 300),
        (pos: (18,12), gold: 200),
    ],

    towns: [
        (
            id:           0,
            pos:          (4,2),
            daily_income: 250,
            recruits: [
                (id: "peasant",   count: 10),
                (id: "swordsman", count: 5),
            ],
        ),
    ],

    neutral_armies: [
        (pos: (7,5),   units: [(id: "goblin", count: 5)]),
        (pos: (13,6),  units: [(id: "orc",    count: 4)]),
        (pos: (17,10), units: [(id: "troll",  count: 2)]),
    ],

    hero: (
        pos:             (1,1),
        name:            "Aldric",
        movement_points: 10,
        army:            [(id: "peasant", count: 5)],
        starting_gold:   500,
    ),
)
```
