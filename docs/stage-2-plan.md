## Принятые решения

### Размеры и константы

| Константа | Значение |
|-----------|----------|
| `TILE_SIZE` | `48.0` пикселей |
| `MAP_WIDTH` | `16` тайлов |
| `MAP_HEIGHT` | `12` тайлов |

### Z-слои спрайтов

| Z | Содержимое |
|---|-----------|
| `0.0` | Тайлы карты |
| `2.0` | Подсветка доступных ходов |
| `3.0` | Hover-подсветка под курсором |
| `4.0` | Герой |

### Цвета тайлов

| Тип | Цвет |
|-----|------|
| `Ground` | `srgb(0.20, 0.55, 0.20)` — зелёный |
| `Obstacle` | `srgb(0.45, 0.45, 0.45)` — серый |
| `Water` | `srgb(0.15, 0.35, 0.80)` — синий |
| Герой | `srgb(0.95, 0.80, 0.10)` — жёлтый |

### Обёртка GameState

`GameState` завёрнут в `GameStateResource(GameState)` — newtype, реализующий `Resource`.
Обновление ресурса автоматически триггерит системы через `Res::is_changed()`.

### Конвертация координат

Карта центрируется вокруг `(0, 0)` мирового пространства Bevy.

- `grid_to_world(pos)` → `Vec2` — центр тайла в мировых координатах
- `world_to_grid(world)` → `Position` — ближайший тайл по мировым координатам

Обе функции покрыты unit-тестами (round-trip) прямо в `mod.rs`.

### Стартовое состояние карты (`render::build_initial_game_state`)

- Карта `16×12`
- 18 клеток `Obstacle` (группы скал)
- 6 клеток `Water` (у краёв)
- Герой `"Aldric"` на позиции `(1, 1)`, `MP: 10/10`
- Город на `(12, 5)` с доходом `250 gold`/день
- Игрок со стартовым запасом `500 gold`

### Управление

| Ввод | Действие |
|------|----------|
| `WASD` / стрелки | Ход героя на одну клетку |
| Левый клик | Ход на клетку под курсором (только смежную) |
| Движение мыши | Hover-подсветка тайла под курсором |

### Порядок систем в `Update`

Системы выстроены в цепочку `.chain()`:
1. `keyboard_input`
2. `mouse_click_input`
3. `update_hover_highlight`
4. `sync_hero_transform`
5. `update_available_moves`
6. `update_movement_ui`

Цепочка гарантирует что изменения `GameState` от ввода применяются до синхронизации визуала.

## Тесты

Три unit-теста в `src/adventure/mod.rs`:

| Тест | Проверяет |
|------|-----------|
| `round_trip_center` | `grid_to_world` → `world_to_grid` для `(7, 5)` |
| `round_trip_origin` | То же для `(0, 0)` |
| `round_trip_far_corner` | То же для `(15, 11)` |
