# Heroes of Rust

Пошаговая стратегия в духе **Heroes of Might and Magic**, написанная на Rust с использованием игрового движка [Bevy](https://bevyengine.org/).

## Описание

Игрок исследует карту приключений, собирает ресурсы, развивает города, нанимает армии, прокачивает героев и сражается в тактических пошаговых боях.

## Требования

- [Rust (stable)](https://rustup.rs/) — версия 1.95 и выше

## Команды разработки

```sh
# Запустить игру
cargo run

# Запустить тесты
cargo test

# Форматирование кода
cargo fmt

# Статический анализ
cargo clippy
```

## Статус

Проект находится в активной разработке. Текущая цель — реализовать минимальную играбельную петлю (вертикальный срез).
